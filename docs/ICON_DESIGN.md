# LifeGather app icon

Asset: `frontend/public/brand/lifegather-icon.png`

Created using the built-in image-generation tool. The PNG preserves the generated transparency and is used for the app identity, browser favicon and Apple touch icon. The cream leaf and three connected nodes connect the app's themes of growing memories and evidence-backed relationships. LifeGather remains a provisional name and visual identity pending clearance.

## Generation prompt

> Use case: logo-brand. Create one finished square app icon for LifeGather, a private personal-memory application that connects possessions, stories, documents and evidence. Match its calm forest-green and warm-ivory visual identity. Design: a dark forest-green rounded-square tile containing a bold warm-ivory leaf whose short branching stem naturally forms a tiny network with three rounded connection nodes. The leaf and connected nodes should read as one coherent original symbol, suggesting living memory and trusted connections. Flat vector-like graphic with precise clean edges, strong silhouette, broad strokes, generous padding and balanced optical centering; clearly recognizable at favicon size. One icon only, front view, no text, no letters, no wordmark, no mockup, no shadow, no gradients, no border, no fine detail. Transparent background outside the rounded-square tile. Tile should occupy almost the full square canvas with about 5% clear exterior margin. Deliver as a square transparent PNG, preferably 512 x 512.

The original generated PNG was copied into the repository without editing or removing its alpha channel.
