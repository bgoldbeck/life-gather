# Five authorized increments

Implement sequentially with no agents. Release each verified feature through the
standing PR/merge/branch cleanup/local image/GHCR rule; do not redeploy.

1. Asset browser: private bounded list/search/current-vs-history filter; detail
   with sourced identity observations, fact history, decision history and exact
   source inspection. Read-only shared domain service, HTTP and typed MCP adapters.
2. Corrections: explicit sourced ownership/lifecycle updates, reversible decision
   reassociation/undo and stale-action protection, preserving all earlier evidence.
3. Uploads: private decoded/size-bounded receipt/nameplate images, safe derivatives,
   user-scoped byte deduplication, authenticated gallery/download, model extraction
   only on explicit consented request, existing proposal review before inventory.
   Backups must include originals; never treat a general attachment as claim proof.
4. Persistent review queue: owned pending proposals and reconciliation reviews,
   paginated filters, same/different/dismiss actions, synchronized durable state.
5. Claude: replaceable provider alongside OpenAI, documented current official API
   contracts, isolated credentials, same consent/usage/cancellation/evidence controls;
   mock provider tests, no live personal data or unapproved paid calls.

For each: inspect current main/instructions, bump minor version/changelog, preserve
data with migrations where needed, test owner/CSRF boundaries, input bounds,
concurrent replay/stale actions, rollback and recovery as applicable; meaningful
UI interactions and synthetic browser verification. Run full checks before release.
Graphify unavailable at start: use source/tests; report refresh availability.
